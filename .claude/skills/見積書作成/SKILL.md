# 見積書作成

「見積書作成してって言ったら作成」する。書式の見本は `assets/書式見本_川嶋様邸.pdf`（川嶋淳子様邸 雨漏り修繕工事）。この見た目に必ず合わせる。

## 作り方
1. 宛先・工事名称・工事場所・工期・支払条件・金額の内訳を聞く。わかっているものは聞かない。足りないものだけ短く確認する。
2. `assets/template_blank.json` をコピーして中身を入れる（記入例は `assets/sample_yoshino.json`）。
3. 実行する: `python3 -I scripts/make_estimate.py 入力.json 出力.xlsx --pdf`
4. PDFにして画像で見た目を確認し、金額の計算も確認してから渡す。

## 書式のルール
- 表題「御 見 積 書」、右上に和暦の日付、宛名は左上。
- 御見積金額は枠で囲み「（消費税込）」を添える。
- 左に工事名称・工事場所・工期・お支払い条件・有効期限、右に会社情報（`assets/company.json`）。
- 内訳は「名称・内訳／数量／単位／金額（税抜）／備考」。大項目は灰色の行で、その金額は小項目の合計。
- 末尾は小計、消費税（10%）、端数値引き、合計（税込）。消費税は端数を切り捨てる。
- 注意書き（※）は表の下に書く。フォントは游ゴシック。
- 税込合計を指定の額にしたいときは `target_total` を入れる。最初の金額の項目で自動調整する。

## 注意
- 業者の原価と上乗せ率など、施主に見せない情報は見積書に載せない。社内用は別シートか別ファイルにする。
- 業者の見積書に0円の項目があるときは、「含む」と書いてよいか確認してから出す。
- 「𠮷」（𠮷野様）は、環境によっては表示されない。送る前に確認する。
- 送付メールは `references/mail_template.md` を使う。

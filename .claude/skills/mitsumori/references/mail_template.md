# メール文の作り方（コピペでそのまま使える完成形）

見積書・請求書などに添えるメール、または「メール文作って」と頼まれたときは、
**件名・宛名・本文・署名を全部入れた完成形**を1つのコードブロックにまとめて出す。
穴埋めや「〇〇」の空欄を残さない（不明な点は聞くか、聞けなければ[ ]で明示して最後に一言添える）。

## 構成
```
件名：【御見積書送付】{工事名称}の件（株式会社ホームクレバー）

{宛名}様

いつもお世話になっております。
株式会社ホームクレバーの都築でございます。

先日ご相談いただきました「{工事名称}」につきまして、
御見積書を作成いたしましたので、添付にてお送りいたします。

■ 御見積金額：￥{税込合計}（消費税込）
■ 工事場所　：{工事場所}
■ 有効期限　：{有効期限日}（発行日より30日間）

ご不明な点やご要望等ございましたら、お気軽にお申し付けください。
ご確認のほど、何卒よろしくお願い申し上げます。
```

## ルール
- 署名は上の形で**毎回必ず**付ける（会社情報は `assets/company.json` と同じ内容）。
- 見積書を添付する場合は、金額・工事名・場所・有効期限を本文に入れて見積書と一致させる。
- 宛名が会社・学校・役所の場合は「御中」「様」を適切に使い分け、部署名・肩書きも入れる。
- 差出人名は既定で都築 将太郎。別の担当者の指定があればそれに従う。
- 請求・催促・お礼・日程調整など見積書以外のメールも、同じ形式（件名＋宛名＋本文＋署名）で出す。
- ユーザーが過去のメール例を渡したら、その文体・言い回しを優先して `references/` に追記する。

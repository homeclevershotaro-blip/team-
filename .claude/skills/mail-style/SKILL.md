# メールの書き方（相手によって分ける）
2026-10-30 代表指示

まず**相手が誰か**を判断する。分からなければ聞く。そのうえで下のルールに合わせて書く。

## 1. 業者・下職あて
当社が発注してお金を払う側。**主導権は当社が持つ。**

1. 決まったことは「〜に決めました」「〜で進めます」と言い切る。「〜でよろしいでしょうか」と聞かない。
2. 頼むことには期限を日時まで付ける（「〜までに出してください」）。
3. 返事の形を決める（可否・項目ごとの金額・日数）。
4. 「恐縮ですが」「お手数ですが」「ご確認のほど」は使わない。お客様あてと同じ書き方にしない。
5. 追加や値段の相談には、その場で答えない。「確認して返事します」で止めて、代表に回す。
6. 署名は3行：
   ```
   株式会社ホームクレバー
   都築 将太郎
   TEL：047-453-0050
   ```

## 2. お客様（施主・オーナー様）あて
丁寧に。ご判断をいただく形で書く。

## 3. 設計者・紹介者・目上の方あて
丁寧に。ただし約束と期限ははっきり書く。

## 書いたあとの確認（業者・下職あて）
- 「よろしいでしょうか」「ご確認のほど」「恐縮ですが」「お手数ですが」が残っていないか
- 期限が日時まで入っているか
- 返事の形（可否・項目ごとの金額・日数）が指定されているか
- 追加・値段の話に、その場で答えていないか
- 署名が3行になっているか

## 補足
- 完成形（件名・宛名・本文・署名）を、コピーして貼り付けられるよう1つのコードブロックにまとめて出す。
- 見積書に添えるお客様宛メールの構成は `mitsumori/references/mail_template.md` に従う（署名もそちらのまま）。

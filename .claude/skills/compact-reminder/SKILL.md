# 容量のお知らせ（/compact の声かけ）

会話の容量がいっぱいになって使えなくなるのが一番困るので、**いっぱいになる前に**ジーニーから声をかける。

## 声をかけるタイミング

次のどれかに当てはまったら、返答の最後にお知らせを付ける。

- フックから「【容量警告】」が届いたとき（Claude Code。届いたら必ず伝える）
- 会話のやり取りがおよそ30往復を超えたとき
- PDF・画像・Excel・長いファイルを何度も読み込んだとき
- 見積書の作り直しや修正を何度も繰り返したとき
- 前の内容を忘れかけている、話が噛み合わないと感じたとき

一度伝えたら、ユーザーがコンパクトするか会話がさらに大きく伸びるまで、同じお知らせを毎回くり返さない。

## 伝え方

返答の本文はふつうに最後まで答えてから、最後に次の文をそのまま付ける。

```
💡 ジーニーより：会話が長くなってきたので、容量がいっぱいになる前にコンパクトした方がいいですよ。
下の1行をそのまま送ってください。

/compact
```

- `/compact` は単独の行にして、そのまま送れるようにする。
- 作業中の内容（見積書の案件名・金額・決まったことなど）を残したいときは、次の形も添える。
  `/compact 〇〇様邸の見積書の内容と決まったことを残して`

## claude.ai（ブラウザ・アプリ）の場合

claude.ai には `/compact` が無いことがある。その場合は次のように伝える。

```
💡 ジーニーより：会話が長くなってきたので、新しいチャットに移った方がいいですよ。
必要な内容をまとめるので「まとめて」と送ってください。まとめを新しいチャットに貼れば続きから作業できます。
```

「まとめて」と言われたら、案件名・お客様名・決まった内容・金額・残っている作業を短い箇条書きにして、1つのコードブロックで出す。

## 自動で知らせる仕組み（Claude Code）

`scripts/context_check.py` は、送信のたびに会話の容量を測って、7割を超えるとジーニーに「【容量警告】」を渡すフック。設定方法は `README.md` を参照。
